치공구 재고조회
품질실 수납함 QR 스캔 · 실시간 재고 확인

데이터 갱신 (사무실 전용)

"절삭공구 재고관리" 앱에서 엑셀로 저장한 파일을 그대로 불러오면 됩니다.
불러온 뒤 페이지 파일 저장을 누르면 최신 재고가 반영된 이 페이지 파일이 새로 다운로드됩니다.
그 파일을 GitHub Pages(배포 위치)에 업로드해 기존 파일을 덮어쓰면, QR을 스캔하는 모든 사람에게 최신 재고가 보입니다.

QR 코드 생성

이 조회 페이지 전체로 연결되는 QR 하나를 만듭니다. 수납함마다 이 QR을 붙여두면,
작업자가 스캔했을 때 검색창이 바로 뜨고 공구명·규격으로 원하는 공구를 찾아볼 수 있습니다.
페이지 배포 주소를 아래에 입력하세요 (예: https://회사.github.io/치공구재고).
