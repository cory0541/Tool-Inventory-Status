품질실 수납함 QR 스캔 · 실시간 재고 확인

실시간 연동 설정 (구글시트 API)

절삭공구 재고관리 앱과 연결된 구글시트 API 주소를 입력하면, 이 페이지가 열릴 때마다
최신 재고를 자동으로 불러옵니다. 설정 후 "페이지 파일 저장"을 눌러 배포하면
이후로는 엑셀을 수동으로 불러올 필요가 없습니다.

데이터 갱신 (수동 백업용)

구글시트 연동을 설정했다면 평소엔 이 부분을 쓸 필요가 없습니다.
연동 전이거나, 오프라인 대비용 백업 데이터를 넣어둘 때만 사용하세요.

QR 코드 생성

이 조회 페이지 전체로 연결되는 QR 하나를 만듭니다. 수납함마다 이 QR을 붙여두면,
작업자가 스캔했을 때 검색창이 바로 뜨고 공구명·규격으로 원하는 공구를 찾아볼 수 있습니다.
페이지 배포 주소를 아래에 입력하세요 (예: https://회사.github.io/치공구재고).
